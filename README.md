# The Gacker

> A habit tracker with stakes. Log a clean day, keep your streak. Log a red day, own it.

Built with React + Vite, wrapped in Capacitor for iOS.

---

## What's in here

```
src/
├── pages/
│   ├── LogTab.tsx          # Daily logging screen (clean or red day + notes)
│   ├── ProfileTab.tsx      # Your calendar history + stats
│   ├── GanalyticsTab.tsx   # Streak, clean days, red days, fire rate
│   └── FeedTab.tsx         # Social feed (coming soon)
├── components/
│   ├── SplashScreen.tsx    # "The Gacker" opening animation
│   └── BottomNav.tsx       # 4-tab bottom navigation
├── lib/
│   └── storage.ts          # Local data layer (localStorage)
└── App.tsx                 # Root — splash → tab shell

ios/                        # Xcode project (generated by Capacitor)
capacitor.config.ts         # App ID, name, build output config
```

---

## Running it locally (web)

You'll need Node.js installed (`brew install node` on Mac).

```bash
npm install
npm run dev
```

Opens at `http://localhost:8080`.

---

## Running it in the iOS simulator

You'll need Xcode installed (free from the Mac App Store).

```bash
npm install
npm run build
npx cap sync ios
npx cap open ios
```

Then hit **▶ Play** in Xcode with an iPhone simulator selected.

### After any code change

```bash
npm run build && npx cap sync ios
```

Then re-run from Xcode.

## Environment variables

Create a `.env` file in the root (never commit this):

```
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_publishable_key
```

If you don't have a Supabase project set up, the app still runs — it stores data in the device's local storage instead.
